# Compact dashboard header

Apply on top of the dashboard hamburger-menu update. Extract into the project root, deploy and reload. No migration is required.

The hamburger is icon-only with an accessible label and a 44px touch target. Your name moves into the menu, while business switching stays beside the hamburger. The dashboard logo, page/header spacing and revenue-card padding are reduced. The logo and menu stay on one row on smaller screens. Date controls and status use tighter spacing, and the status badge and check times share a row. Long check details remain horizontally scrollable without adding lines.

Only dashboard.html and live-dashboard.css are changed. Kitchen queue sizing and icons are unaffected.
